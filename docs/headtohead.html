How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one AI-powered automated investing app for a retail investor, Clera or {rival}?" Asked in both name orders, 5 fresh runs each (50 answers total), via the OpenAI API (gpt-4o) directly, with a system prompt forcing a decisive pick.
  • Open comparison question: "Clera vs. {rival}: which should I choose?" Asked once per order (10 answers), no system prompt — this is where the reasoning notes above come from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations.
  • Rival list, tightened: this page compares Clera against the apps that actually share its pitch — chat-based AI stock picks and trade execution (Titan, Public.com's Alpha, Walnut, Magnifi, Composer's Trade with AI) — not generic robo-advisors like Wealthfront or Betterment, which manage portfolios algorithmically with no conversational AI front end. A tighter, honest list beats a longer, loosely-related one.
  • The headline finding: there is still no real competitive signal here. In every one of the 10 open-comparison runs, the model never once correctly identified Clera — it repeatedly hedged with phrasing like "not a widely recognized financial service," and in one run (vs. Titan) it defaulted to describing an entirely unrelated company, Clera Windows and Doors. Several rivals fared little better: Walnut got a total hedge in both runs, and Composer was confused with the unrelated (and far better-known) PHP dependency-management tool of the same name in one run. This is a page of brand-recognition artifacts, not a judged comparison.
  • Walnut and Public.com land closest to even (5 of 10 each) — both are smaller brands the model is also uncertain about, so an unrecognized Clera doesn't automatically lose. Magnifi and Composer each won 7 of 10, and Titan won 8 of 10 — in every case because the rival's name resolved the model's uncertainty more decisively than Clera's did, not because of any real feature comparison.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — the open-comparison answers made almost no specific, checkable claims about Clera itself (since the model didn't recognize it), so there isn't a real "worth checking" fact sheet for this project. Also not covered: any run through the ChatGPT web app, or any run while logged in.
