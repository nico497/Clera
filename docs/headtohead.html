How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one AI-powered automated investing app for a retail investor, Clera or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly, with a system prompt forcing a decisive pick.
  • Open comparison question: "Clera vs. {rival}: which should I choose?" Asked once per order (12 answers), no system prompt — this is where the reasoning notes above come from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations.
  • The headline finding: there is no real competitive signal here at all. In every one of the 12 open-comparison runs, the model said it did not recognize "Clera" as a financial platform — it repeatedly hedged with phrasing like "not a widely recognized financial service," and in one run (vs. Titan) it defaulted to describing an entirely unrelated company, Clera Windows and Doors. The forced-pick numbers below (sweeps against four rivals, near-ties against the other two) are an artifact of how the model resolves uncertainty when forced to pick a name it doesn't know, not a judgment about product quality.
  • Wealthfront, Betterment, M1 Finance and SoFi Invest were swept 10 of 10 against an unrecognized Clera — the model consistently defaulted to the well-known, well-documented brand. Public.com was close to even (5 of 10) and Titan actually won the majority (8 of 10) — likely because Titan is itself a smaller, less universally known brand, making the forced pick closer to a coin flip between two names the model wasn't confident about.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — the open-comparison answers made almost no specific, checkable claims about Clera itself (since the model didn't recognize it), so there isn't a real "worth checking" fact sheet for this project. Also not covered: any run through the ChatGPT web app, or any run while logged in.
