How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one AI tool to help a job seeker get hired at a startup, Clera or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly, with a system prompt forcing a decisive pick.
  • Open comparison question: "Clera vs. {rival}: which should I choose?" Asked once per order (12 answers), no system prompt — this is where the reasoning notes come from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations: they're the model's general knowledge, not a sourced comparison.
  • Rival list: Jack & Jill, Wellfound, Jobright AI, Hunter, JobCopilot and WonsultingAI, chosen as AI tools that help job seekers get hired, taken from Product Hunt's alternatives list, a Stork review and web search. Hunter and Wellfound came from search results only, and none were checked feature by feature.
  • The headline finding: in all 12 open answers the model never identified Clera. It guessed windows and doors, customer management, business operations or data analysis, or asked for more context. Only Wellfound was clearly recognized. Others were guesses from the name, such as Hunter taken for Hunter Douglas blinds.
  • Wellfound won 10 of 10, and Jobright AI, JobCopilot and WonsultingAI each won 9 of 10. Jack & Jill is Clera's one win (9 of 10), though the model didn't know that name either. Hunter swings with name order (Clera 0 of 5 when named first, 4 of 5 when Hunter is), a sign the model is guessing.
  • Not yet covered: the hiring-company side of Clera (startups paying per hire), pricing, integrations and support as separate scored dimensions, any run through the ChatGPT web app, and any run while logged in.
